# Cross-site documentation map

Forge splits documentation by **concern**, not by hiding Lenses:

| If you need… | Start here |
|--------------|------------|
| **Lenses product** — install, Studio, Wizard, security, APIs | This site (**[lenses.forgesdlc.com](https://lenses.forgesdlc.com)**) and **[forge-lenses on GitHub](https://github.com/autowww/forge-lenses)** |
| **Forge SDLC methodology** — adoption narrative, knowledge base | **[forgesdlc.com](https://forgesdlc.com/)** |
| **Blueprints framework** — ceremonies, templates, process handbook | **[blueprints.forgesdlc.com](https://blueprints.forgesdlc.com/)** (Lenses quickstart hub: **[Blueprints → Lenses](https://blueprints.forgesdlc.com/lenses/)**) |
| **Kitchen Sink** — layouts, components, diagram templates | **[Kitchen Sink handbook](https://ks.forgesdlc.com/)** · **[forgesdlc-kitchensink (GitHub)](https://github.com/autowww/forgesdlc-kitchensink)** — diagram keys for **this** handbook live in [Diagram catalog](diagram-catalog-lenses.md). |
| **Maintainer-only** — ADRs, raw HTTP tables, release mechanics | **[Maintainer handbook (GitHub)](https://github.com/autowww/forge-lenses/blob/main/docs/maintainer/index.md)** — not on the lean public static build |

## Rules of thumb

1. **Evaluators** stay on Lenses + Blueprints Lenses hub until they need process depth.
2. **Operators** pair [Security and local-first](17-security-and-local-first.md) with [Configuration reference](../reference/config-env.md).
3. **Automation authors** pair [Schemas and API (builders)](16-schemas-and-api-for-builders.md) with JSON [examples](19-examples-hub.md).

This page satisfies the prompt-pack **`docs/public/cross-site-map.md`** intent using the `docs/handbook-public/` layout (same static handbook build).

Use **[Forge SDLC methodology](https://forgesdlc.com/)** for executive framing, **[Blueprints](https://blueprints.forgesdlc.com/)** for ceremonies/templates, then return here for executable Studio/Wizard/API guidance—avoid duplicate canon across sites; prefer links over verbatim copies.
