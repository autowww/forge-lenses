# Changelog (documentation)

This static site tracks **handbook** updates continuously; semantic product versioning follows **forge-lenses** git tags.

- **Release notes** — see **[GitHub Releases](https://github.com/autowww/forge-lenses/releases)** for tagged builds.
- **Doc-only changes** — browse commits touching `docs/` on the default branch; CI runs **`scripts/check-docs.sh`** on every PR.
- **Breaking URL moves** — recorded in **[`docs/redirects.yaml`](../redirects.yaml)** when slugs change.
