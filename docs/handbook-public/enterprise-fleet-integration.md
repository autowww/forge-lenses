# Enterprise — Forge Fleet integration

## What it is

Fleet integrations reuse the same **`POST`** discipline as other automation surfaces — configure gateways only after reviewing **[Schemas and API (builders)](16-schemas-and-api-for-builders.md)**, the **[HTTP API route catalog](../generated/api-routes.md)**, and the maintainer prose on GitHub: [HTTP API and routes source](https://github.com/autowww/forge-lenses/blob/main/lenses/website/http-api-and-routes.md).

## Verify

Fleet bearer material is stored like production secrets and rotated with your org policy.
