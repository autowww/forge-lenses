# Roadmap (public summary)

Forge Lenses evolves as a **local-first** workspace dashboard with optional AI and Fleet integrations. This section is intentionally high level; detailed RFCs live in **ADRs** (maintainer / full handbook builds).

## Near term

- Harden **Studio** navigation and Docs Health operator flows.
- Keep **Wizard** experimental surfaces clearly flagged; improve session recovery UX.
- Expand **builder** schemas in lockstep with `lenses/serve.py` (CI enforces coverage).

## Mid term

- **OIDC + RBAC** polish for enterprise installs (see maintainer ADRs on governance sprints).
- Deeper **Forge Fleet** task templates for regulated environments.

## How to influence priorities

Open **[GitHub issues](https://github.com/autowww/forge-lenses/issues)** with problem statements (not feature orders). For methodology alignment, also see **[Blueprints Lenses hub](https://blueprints.forgesdlc.com/lenses/)**.
