# Studio explore screenshots

PNG manifests from **`npm run studio-explore`** / **`studio-explore:full`** are written **outside this repo**:

**`<workspace-parent>/.workspace-screenshots/forge-lenses/studio-explore/<run-id>/`**

From a typical clone at `…/Code/forge-lenses/`, that resolves to:

**`…/Code/.workspace-screenshots/forge-lenses/studio-explore/<run-id>/`**

See `desktop/studio-explore/README.md` and the workspace file **`.workspace-screenshots/README.md`** (sibling of `forge-lenses/`).
