# Maintainer documentation

This folder holds **internal** handbook sources that are **not** published on [blueprints.forgesdlc.com](https://blueprints.forgesdlc.com/lenses/).

- **`website/`** — Former `docs/website/` pages (interface/dashboard/registry/plan-map style) kept for contributors. Public, task-centric docs live under **`docs/handbook-public/`** and are what the Blueprints site builds.

Other maintainer material: repo-root **`docs/`** (ADRs, studio shell notes), **`lenses/website/`** (package reference), **`lenses/fa-tutorial-md/`** (tutorial sources).
