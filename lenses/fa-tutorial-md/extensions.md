# Future extensions

This page is a **placeholder** for later **lenses** capabilities (extra panels, importers, custom registry-driven views).

## Hook points (planned)

- Optional **`workspace-registry.json`** at the **forge-lenses** repo root — already supported in v1 for URL overrides, ignored top-level directories, and website labels. For end-user workspace setup see the published [Workspace setup](https://blueprints.forgesdlc.com/lenses/guides/03-workspace-setup.html) guide; maintainer-oriented registry detail lives under **`docs/maintainer/website/`** in the repo.
- A future **`lenses/extensions/`** directory or documented plugin entry points may be added without changing the core scan contract.

v1 ships registry overrides and this roadmap page; a full plugin API is not implemented yet.
